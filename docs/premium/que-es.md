# Qué es premium

Premium es un nivel de Kigo para servidores que necesitan más potencia. No es una suscripción: se obtiene por códigos puntuales.

## Diferencias concretas

| Función | Gratis | Premium |
|---|---|---|
| Anti-raid completo | ✅ | ✅ |
| Automod completo | ✅ | ✅ |
| Verificación | ✅ | ✅ |
| Lista blanca | ✅ | ✅ |
| Comandos de moderación | ✅ | ✅ |
| Soporte estándar | ✅ | ✅ |
| Backups manuales | ✅ (exportar JSON) | ✅ + backups automáticos diarios |
| Retención de logs | Ilimitada en Discord | Ilimitada en Discord + 1 año de backup en Kigo |
| Comandos masivos de moderación | ❌ | ✅ (`/ban-all`, `/kick-all` con filtros) |
| Badge premium | ❌ | ✅ |
| Soporte prioritario | ❌ | ✅ (respuesta < 24h en horario laboral) |

## Quién debería pedir premium

**No lo necesitas si:**

- Tu servidor tiene menos de 500 miembros.
- Tienes un solo moderador.
- No te importa hacer backups manuales.

**Sí lo necesitas si:**

- Tu servidor tiene más de 2000 miembros.
- Quieres backups automáticos sin preocuparte.
- Necesitas soporte rápido cuando algo falla.
- Quieres aparecer como "servidor verificado premium" en el `/botinfo`.

## Cómo se distribuyen los códigos

Los códigos premium los genera el autor del bot. Cada código:

- Es una cadena alfanumérica de 14 caracteres (ej: `KIGO-abc123XYZ456`).
- Tiene una duración específica (1 semana, 2 semanas, 1 mes, 1 año, o infinito).
- Solo se puede canjear una vez.
- Solo se puede canjear en un servidor.

## Limitaciones de los códigos

- Un código infinito es válido hasta que Kigo lo revoque manualmente.
- Un código de 1 año expira exactamente 1 año después de canjearse, no de generarse.
- No hay reembolso de códigos (si tu servidor se queda inactivo, el código sigue contando).
- Un servidor solo puede tener un código activo a la vez. Si canjeas otro, se acumula sobre el actual (no se reinicia).
